# Chennai Suburban Railway Transit Map

This is a simplified and easy-to-read transit map of the Chennai Suburban Railway network.

## Features
- Clean and easy-to-understand design
- Includes operational, under-construction, and planned lines
- Covers suburban railway, metro, and metrolite networks

## Tools Used
- Inkscape
