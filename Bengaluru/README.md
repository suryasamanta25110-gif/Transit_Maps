# Bengaluru Metro Railway Transit Map

This is a simplified and easy-to-read transit map of the Bengaluru Metro Railway network.

## Features
- Clean and easy-to-understand design
- Includes operational lines only
- Includes symbols to show nearby railway stations, bus terminals and commercial airports

## Tools Used
- Inkscape
